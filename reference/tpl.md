# Lookup-table for family, genus, and species names for ThePlantList gymnosperms

These names are from <http://www.theplantlist.org/>, collected on
2015-11-11, and are from version 1.1 of their data. This data is used in
the function
[`phylomatic_names()`](https://docs.ropensci.org/brranching/reference/phylomatic_names.md)

## Format

A data frame with 23,801 rows and 2 variables:

- family: family name

- genus: genus name

## Source

<http://www.theplantlist.org/>
